## Current Layer Responsibilities

```text
Controller  -> HTTP request and response
Service     -> business flow and business exceptions
Repository  -> legacy JdbcTemplate access removed after migration
Mapper      -> MyBatis-Plus database access during migration
Entity      -> database-row model
DTO         -> data crossing the API boundary
Result<T>   -> common response envelope
```

## Important Decisions

- Use `GET /users` for a list and `GET /users/{id}` for one user.
- Use `POST /users` to create, `PUT /users/{id}` to update, and `DELETE /users/{id}` to delete.
- IDs are generated by MySQL `AUTO_INCREMENT`, not by Java collection size.
- Keep SQL parameterized with `?` placeholders.
- Keep project source and Maven compilation encoding at UTF-8.
